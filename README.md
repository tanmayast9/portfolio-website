# portfolio-website

Personal portfolio website for Tanmaya Tilavalli — built with React, Tailwind CSS, and Framer Motion.

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Live Site

Deploy the `dist/` folder to Vercel, Netlify, or GitHub Pages.
